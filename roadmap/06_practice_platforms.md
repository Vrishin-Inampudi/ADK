# Phase 6: Practice Platforms (run in parallel with everything)

Aim for ~3-4 hours/week. Write up each room/challenge you finish (what, how, what you learned).

## Order
1. [ ] OverTheWire Bandit (levels 0-20): Linux/shell basics. https://overthewire.org/wargames/bandit/
2. [ ] TryHackMe: Pre Security, then Jr Penetration Tester or SOC Level 1. https://tryhackme.com
3. [ ] PortSwigger Web Security Academy: SQLi, XSS, auth labs. https://portswigger.net/web-security
4. [ ] Blue Team Labs Online: log and incident investigations. https://blueteamlabs.online
5. [ ] CyberDefenders: blue team challenges with pcaps/logs. https://cyberdefenders.org
6. [ ] pwn.college: deeper systems security (longer-term). https://pwn.college
7. [ ] Hack The Box (easy machines), after TryHackMe. https://www.hackthebox.com
8. [ ] Cryptopals: https://cryptopals.com

## Habits
- Take notes in your own words; screenshots of key steps
- After each challenge, ask: "what log would this have left? could my tool detect it?"
- Never use these techniques outside authorized environments
